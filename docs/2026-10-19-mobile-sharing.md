# 휴대폰·건설 메뉴·공개 초대 준비

요청: 시설 건설 아래가 잘 안 보이는 문제, 전장 과도한 밝기, 개인 무기 패널 색상 불일치를 수정하고 휴대폰에서 카톡으로 친구를 초대한다.

구현: 회녹색 콘크리트 중간 밝기 팔레트로 전장·UI·무기를 통일한다. 건설 카드 글씨·가격을 키우고 잠금 카드를 흐리게 처리하는 대신 색을 구분한다. 좌우 넘김 버튼과 스크롤바를 추가한다. 작은 가로 화면에서는 시작 버튼 안내를 축소해 전장 클릭을 가리지 않게 한다. 세로 휴대폰에서도 회전 가림막 없이 전장·건설 메뉴를 먼저 보여주고 무기·상세는 아래에서 스크롤한다.

기존 4인 WebSocket 게임과 방 링크를 공유하는 동작을 유지하고 버튼을 '카톡으로 초대'로 명확히 표시한다. 오프라인 HTML은 1인용이므로 초대 기능을 비활성화한다. 실제 인터넷 공동 플레이는 Node/WebSocket 공개 서버가 필요하다.

배포 준비: render.yaml에 기존 Docker 이미지를 사용하는 무료 단일 서비스·healthCheckPath·환경 변수를 선언한다. 유료 디스크/서비스는 생성하지 않는다. 배포 버튼과 쉬운 한국어 안내를 docs/phone-and-friends.md에 제공한다. 무료 서버는 재시작 시 방과 파일 기반 뿌·구매 기록을 잃을 수 있음을 명시한다.

공개 배포 상태: 연결된 호스팅 도구나 인증된 Render 계정이 없다. GitHub HTTPS 프록시로 소스 업로드는 가능하지만 별도 호스팅 계정에 대한 권한을 제공하지 않는다. 이 실행 환경에서 Render 배포 페이지 HTTP 요청은 403으로 차단되었다. 따라서 Render 배포 실행과 외부 공개 주소·실제 HTTPS/WebSocket은 검증되지 않았다. 마지막 단계는 사용자 계정으로 배포 버튼을 열어 서비스를 만드는 것이다. 아직 공개 게임 링크가 만들어졌다고 안내하지 않는다.

검증: 세로 회전 가림막 테스트 RED→GREEN. 가로 화면 배치 회귀는 축소된 전장 위 안내 패널이 클릭을 가리는 문제로 실패했고 안내 축소로 수정했다. 목록 넘김도 상태 갱신 시 DOM을 불필요하게 다시 생성하여 스크롤이 중단되는 실패를 재현한 뒤, 실제 카드 내용이 바뀔 때만 다시 그리도록 수정했다. 가로 배치·목록 넘김·세로 화면 집중 검사3개가 통과했다. 서버54개 통과. 최종 브라우저·오프라인 결과는 아래 기록.

최종 검증: npm test 54/54, npm run test:browser 18/18, npm run test:solo 1/1 통과. 데스크톱과 가로 휴대폰 스크린샷을 확인했고 세로 화면에서도 건설 목록·무기 영역 접근을 검증했다. Render YAML을 파싱하여 무료 플랜과 /health를 확인했으나 실제 외부 배포 검증은 계정 연결 전까지 보류한다. 실기기 안드로이드·카톡 인앱 브라우저 확인은 별도다.
