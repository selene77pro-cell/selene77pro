# LAST OUTPOST · 최후의 방어선

별명과 방 코드로 입장하는 **1~4인 좀비 협동 디펜스**입니다. 혼자 시작한 방에도 친구가 합류할 수 있습니다. 전투 자금은 **찌**, 영구 클리어·실패 보상은 **뿌**입니다.

## Windows에서 시작하기

Node.js 24 이상을 한 번 설치해야 합니다. 압축을 푼 폴더에서 `start-game.cmd`를 더블클릭하면 필요한 실행 의존성을 설치하고 서버가 준비된 뒤 브라우저를 엽니다. 실행 중 검은 창은 켜두세요. 이 실행 도우미는 Windows 환경에서의 실기기 검증이 아직 필요합니다.

직접 실행하려면 `package.json`이 있는 폴더에서 명령창을 여세요. Node.js를 설치했는데도 찾지 못하면 같은 창에서 아래를 실행합니다.

```bat
set "PATH=C:\Program Files\nodejs;%PATH%"
node -v
npm.cmd ci
npm.cmd start
```

`LAST OUTPOST listening on port 3000`이 나오면 **본인 PC의 브라우저 주소창**에 `http://localhost:3000`을 입력합니다. Node 설치 파일을 받는 것과 실제 설치 완료는 다릅니다. `node -v`에서 버전이 나오는지 확인하세요.

기존 버전에서 업데이트할 때는 기존 서버 창에서 Ctrl+C로 종료하고, 새 ZIP을 별도 폴더에 푸세요. 기존 `data` 폴더가 있으면 백업 후 새 폴더로 복사해 뿌·구매 기록을 유지합니다. 이전 서버가 포트 3000에서 실행 중이면 새 버전 서버가 시작되지 않습니다.

## 개발 실행

```sh
npm ci
npm start
```

기본 `HOST=0.0.0.0`, `PORT=3000`이며 환경 변수로 변경할 수 있습니다. `GET /health`가 `{"ok":true}`면 서버가 응답하는 상태입니다. 별도 DB, 카카오 로그인이나 API 키는 필요하지 않습니다.

## 입장과 조작

- **혼자 새 방 시작:** 별명을 입력하고 누르면 오래된 초대 주소를 무시하고 새 방의 준비 시간을 시작합니다.
- **친구 입장:** 별명과 6자리 방 코드를 입력하거나 초대 URL에서 작전 시작을 누릅니다. 최대 4명까지 가능합니다.
- **일반 방 만들기:** 방 코드를 비우고 작전 시작을 누른 뒤, 전투 화면의 방어 시작을 누를 수도 있습니다.
- **돈 벌기:** 전장의 화면을 한 번 클릭·탭할 때마다 자신에게 **+1찌**. 시설 선택·배치 클릭도 포함하며, 드래그·메뉴·무기 버튼은 제외합니다.
- **시설:** 아래 건설 목록에서 선택하고 경로·건물 밖 빈 공간에 배치합니다. 자신의 시설은 4단계 강화와 투자액 75% 판매가 가능합니다.
- **배속:** 방장만 1×/2×/3×를 선택하며 모든 플레이어에게 같이 적용됩니다. 방장이 접속을 끊으면 연결된 동료에게 조작권이 넘어갑니다.
- **전장 보기:** +/−로 확대·축소, 드래그로 이동, ⌖로 전체 보기. Esc로 시설 선택 취소. 휴대폰은 가로 화면을 사용합니다.
- **음악·효과음:** 시작 버튼을 누른 뒤 재생됩니다. 음악·효과음 음량과 음소거를 별도로 조절합니다. 소리 차단 시 소리 켜기를 눌러 재시도할 수 있으며 게임 진행에는 영향이 없습니다.

웨이브 완료마다 `55 + 전체 웨이브 × 5`찌를 전원에게 지급합니다. 은행 수익은 은행 소유자에게만 추가 지급합니다. 처치 보상은 실제 피해 기여에 따라 나눕니다. 100개까지 시설을 배치할 수 있고 소환 기지마다 군인 최대 4명이 전투합니다. 보병·돌격병·방패병은 좀비에게 접근해 접촉 전투를 하며 체력이 0이 되면 죽습니다. 중화기·드론·전차·워메크는 원거리 역할입니다.

## 개인 무기

찌로 구매하며 새 게임에서는 초기화됩니다. 무기를 구매·선택한 뒤 **발사 시작**을 누르면 게임 시간 1초마다 발사하고, 다시 누르면 멈춥니다. 타워는 별도로 자동 공격합니다.

| 무기 | 가격 | 공격 |
| --- | --- | --- |
| 기본 총 | 1000찌 | 단일 80 피해 |
| 산탄총 | 2500찌 | 최대 5마리에 각각 30 피해 |
| 레일 라이플 | 7000찌 | 단일 450 관통 피해 |
| 플라스마 캐논 | 15000찌 | 250 범위 피해 |
| 핵폭탄 | 사용당 5000찌 | 보스 외 현재 좀비 즉사 |

핵폭탄은 별도 사용 확정 버튼을 누릅니다. 보스 체력에는 영향을 주지 않고 분열도 억제합니다. 아직 출현하지 않은 적은 이후 정상 출현합니다. 방 전체에 30게임초 대기시간이 적용되며, 대상이 없거나 보스만 있으면 돈을 차감하지 않습니다.

## 지역·난이도·좀비

도시 → 공장 → 군사기지 → 항만 → 연구소의 5개 지역을 난이도마다 각 10웨이브씩 진행합니다. 지역 마지막에는 서로 다른 보스가 나오고, 지역 이동 시 시설 건설·강화비를 전액 환급합니다. 잔액과 해금은 유지됩니다.

**보통 → 어려움 → 지옥 → 불가능**으로 진행하며, 총 200웨이브를 완료하면 전체 승리입니다. 기존 무한 반복 버전을 이 클리어 구조로 변경했습니다. 각 난이도 완료 시 기지 내구도를 회복합니다. 기지 체력이 0이면 패배합니다.

질주(작고 빠름), 거대(높은 체력), 장갑(일반 피해 감소), 재생(화염으로 회복 억제), 분열(죽으면 작은 3마리)과 일반 좀비가 등장합니다. 분열체는 다시 분열하지 않으며 처치 보상을 중복 지급하지 않습니다. 어려움부터 화염·냉기·전기 저항을 가진 적이 섞입니다. 원소 저항은 완전 면역이 아닙니다.

## 뿌 보상·상점·인벤토리

난이도 클리어 보상은 보통 200, 어려움 400, 지옥 800, 불가능 1600뿌입니다. 실패 보상은 현재 난이도의 완료 웨이브 수를 n이라고 할 때 `(5+2n) × 난이도 배율(1/2/4/8)`입니다. 다음 게임에도 남으며 클릭이나 찌 교환으로 얻을 수 없습니다.

| 구매 자격 | 추가 타워 | 영구 구매 | 전투 건설 |
| --- | --- | --- | --- |
| 보통 클리어 | 방패병 기지 | 200뿌 | 300찌 |
| 어려움 클리어 | 중력탑 | 400뿌 | 600찌 |
| 지옥 클리어 | 궤도포 | 800뿌 | 1000찌 |
| 불가능 클리어 | 워메크 기지 | 1600뿌 | 1600찌 |

기본 18종은 그대로 보유하고, 새로 구매한 타워를 포함한 장착 목록은 **다음 방 입장부터** 적용합니다. 인벤토리에서 교체할 수 있으며 기본 기관총·막사·은행은 항상 장착됩니다. 진행 중에는 장착 목록을 변경하지 않습니다. 기본 시설은 클리어 웨이브 5마다 산탄/냉각 → 저격/돌격 → 박격포/보급 → 화염/중화기 → 전기/의무 → 미사일/드론 → 레일/플라스마 → 전차 순으로 열립니다.

## 저장과 재접속

기본 영구 저장 위치는 `data/profiles.json`이며 환경 변수 **`OUTPOST_DATA_DIR`**로 바꿀 수 있습니다. 서버 재시작 후에도 뿌·구매·장착·클리어 기록을 복원합니다. 저장 경로에는 쓰기 권한이 필요하며, 손상된 파일은 덮어쓰지 않고 오류로 중단합니다. 보상 저장 실패는 화면에 알리고 자동 재시도합니다. 저장 실패가 계속되면 서버 종료 전에 저장 공간과 권한을 복구하세요. 아직 저장하지 못한 보상은 서버 프로세스를 종료하면 잃을 수 있습니다.

프로필 복귀 키는 브라우저 localStorage에 보관합니다. **브라우저 데이터를 지우거나 다른 기기로 옮기면 같은 프로필이 자동 복원되지는 않습니다.** 공유 URL에는 비밀 키를 넣지 않습니다. `data/`는 Git·게임 ZIP·Docker 이미지에 넣지 마세요. 공개 호스팅은 영속 볼륨으로 이 폴더를 유지해야 합니다.

진행 중 방은 서버 메모리에만 있으므로 재시작 시 사라집니다. 연결이 끊긴 자리는 실제 시간 2분 보존하며 같은 브라우저의 링크·방 코드 재입장으로 복구합니다. 전원 접속이 끊기면 전투는 멈춥니다. 보존 시간이 끝나면 해당 플레이어의 시설·병사를 제거합니다.

## 검증

```sh
npm test
npm run test:browser
npm run test:solo
```

브라우저 테스트는 `/usr/bin/chromium`을 사용합니다. 다른 환경은 `CHROMIUM_PATH`로 지정하세요. 전투·보상·디스크 실패·재시작과 실제 WebSocket 4인 접속을 검사하고, 브라우저에서 클릭/드래그 구분·총/핵폭탄·상점·배속·오디오 활성화·기존 자리 복귀를 검증합니다. 실제 음악 청취 품질과 카카오톡 인앱 브라우저의 실기기·200웨이브 장기 밸런스 검증은 별도로 필요합니다.

`npm run build:solo`는 `dist/last-outpost-solo.html`을 생성합니다. 이는 외부 요청 없이 같은 전투 규칙을 연습하는 **1인 전용 오프라인 패키지**로, 창을 닫으면 프로필도 초기화됩니다. 협동용 배포를 대체하지 않습니다. 관리형 Chromium의 file URL 차단 때문에 자동 검사는 HTML 내용을 직접 로드합니다.

## 친구에게 실제 접속 주소를 보내려면

다른 집·휴대폰에서 함께하려면 **HTTPS와 WebSocket을 지원하는 공개 서버**가 필요합니다. 본인 PC의 localhost 주소나 소스 ZIP은 친구용 접속 주소가 아닙니다. 한 서버 프로세스로 실행하고 리버스 프록시에서 WebSocket Upgrade와 Host를 전달하세요. `npm ci --omit=dev`와 `npm start`로 서비스하고 `OUTPOST_DATA_DIR`를 영속 저장 경로로 지정합니다. 기본 방 상한은 100개이며, 한 방의 살아 있는 적은 최대 200마리입니다. 여러 서버 인스턴스 사이의 방 공유는 지원하지 않습니다.

Dockerfile이 포함되어 있습니다. ChatGPT Sites 생성·게시 API는 현재 작업에 제공되지 않아 Sites 등록·서버 지원 여부는 검증하지 못했습니다. GitHub 코드 게시와 공개 플레이 사이트 배포를 구분합니다.
