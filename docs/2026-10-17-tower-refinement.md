# 군인 경로·타워·매뉴얼 수정

사용자 요청: 기지 출발 군인이 한 길로만 가는 문제 해결, 읽기 쉬운 매뉴얼, 기존 타워 세 개를 광역·관통·29,000찌 초강력 타워로 교체, 보스전 모든 적 육상 집결, 웨이브 완료 시 타워 회복.

변경: 시설 가까운 경로 선택 대신 모든 모집 시설에서 생성되는 병력을 두 육상 경로에 번갈아 배정한다. 지형을 벗어나지 않고 기지에서 출발한다. 보스 스테이지10/20/30의 모든 일반 적·증원·분열체를 육상 경로로 강제한다. 스테이지 완료 시 살아 있는 시설의 체력을 최대치로 복원한다. 이미 파괴된 시설은 부활하지 않는다.

선택한 교체 대상: 산탄 포탑 → 광역공격(350찌), 레일건 → 관통(1,200찌), 플라스마탑 → 밸런스 붕괴(29,000찌). 프로필 호환을 위해 내부 식별자는 유지한다. 관통은 장갑 무시뿐 아니라 같은 직선 위 여러 적을 실제로 공격한다. 기존 개인 산탄총·레일 라이플·플라스마 캐논은 별도 무기이므로 유지한다.

매뉴얼: 시작 화면과 전투 상단에 강조 버튼을 배치하고 모달 안에 큰 글씨·번호·가격·조작법·회복 규칙을 표시한다. 타워 상세에서도 체력과 회복 시점을 표시한다. 단일 HTML을 재생성하여 GitHub ZIP에 포함한다. 공개 온라인 호스팅은 요청에 따라 보류한다.

검증: 군인 분산·보스 육상·회복 테스트의 실패를 확인 후 구현하여 통과했다. 관통 직선/비직선·광역 피해·29,000찌 차감 검사도 포함한 서버54개가 통과했다. 기존 브라우저15개와 새 매뉴얼1개, 오프라인1개가 모두 통과했다. 매뉴얼의 15px 본문과 실제 화면 스크린샷도 확인했다.
