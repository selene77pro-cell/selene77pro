# 좀비 디펜스 성장 시스템 설계

## 사용자 목표와 변경 범위
기존 별명·방 코드 1~4인 협동 게임에 접촉 전투 병사, 최대 3배속, 난이도 진행, 영구 보상과 타워 상점·인벤토리, 배경음악·효과음, 플레이어 무기와 핵폭탄을 추가한다. 사용자 확인: 전투 자금은 찌로 유지하고 **보상만 뿌**로 한다. 화면 클릭으로 돈을 벌고 무기 조작은 별도 버튼으로 제공한다. 기존 작전 시작 문제는 아직 사용자 PC에서 원인을 확인하지 못했으므로 해결됐다고 주장하지 않으며, 이번 검증에서도 1인 입장과 시작을 필수로 확인한다.

## 구현 방식 선택
권장 방식은 기존 Node 서버가 전투와 보상·구매를 판정하고 프로필을 파일로 저장하는 방식이다. 기존 서버를 재사용하며 계정 로그인은 추가하지 않는다. 브라우저에만 보관하면 협동 보상 검증 및 여러 창의 잔액 일치가 어려우며, 외부 계정·DB 방식은 별도 서비스 설정이 필요하다. 따라서 최초 버전에서는 서버 저장과 같은 브라우저의 프로필 복귀 키를 사용한다.

## 두 종류의 돈
- 찌: 처치·웨이브·은행 수익, 전투 중 건설·강화·판매에만 사용. 웨이브 완료 보상은 기존 `55 + 전체 웨이브 × 5`를 유지하고 완료 안내에 실제 지급액을 표시한다. 다른 난이도로 진행해도 전투 중 잔액은 유지한다. 새 게임은 650찌로 시작한다.
- 클릭 수입: 사용자 최신 요청에 따라 전용 돈 버튼 대신 전장 화면 클릭·탭 한 번당 본인에게 1찌를 지급한다. 대기·준비·전투 중 사용할 수 있고 종료 후에는 지급하지 않는다. 드래그·확대·스크롤은 클릭으로 세지 않는다. 전장의 시설 선택·배치 클릭도 한 번으로 세되, 메뉴·구매·강화·무기 버튼은 클릭 수입에 포함하지 않는다. 서버가 접속 플레이어에게 직접 지급하며 클라이언트가 보낸 수입액은 신뢰하지 않는다. 1/2/3배속 모두 클릭 한 번당 1찌로 동일하고 뿌는 지급하지 않는다. 기존 초당 요청 제한 범위에서 동작하며 눌러서 번 금액을 즉시 표시한다.
- 뿌: 난이도 클리어와 실패 시 개인 프로필에 지급하고 다음 게임에도 남는다. 상점의 영구 타워 구매에만 사용하며 찌와 교환하지 않는다.
- 보상은 서버가 한 번만 정산한다. 새로고침·중복 종료·재접속으로 다시 지급하지 않는다. 중도 합류자는 합류 이후 정산 시 참여 중인 난이도의 보상을 받는다. 2분의 자리 보존 기간 내 연결이 끊긴 플레이어도 정산에 포함한다.

## 난이도와 게임 종료
보통 → 어려움 → 지옥 → 불가능 순서로 진행한다. 난이도마다 도시·공장·군사기지·항만·연구소 5개 맵을 각 10웨이브씩 방어하며 각 맵 마지막에 보스가 나온다. 전체 웨이브 번호는 유지하고 난이도·지역 내 진행도는 별도로 관리한다. 난이도마다 적 체력·공격력·수량을 올리되 전역 웨이브의 기존 지수 증가와 중복 적용하지 않는다. 난이도별 기본 체력 배율은 1/2/4/8, 공격력 배율은 1/1.5/2/3, 수량 배율은 1/1.15/1.3/1.5로 한다. 기존 맵 전환 전액 환급 규칙은 유지한다.

제안하는 종료 규칙: 불가능의 다섯 번째 맵까지 완료하면 전체 승리로 정산하고 상점으로 이동할 수 있다. 다시 플레이할 수 있으며 기존의 끝없는 지역 반복 대신 명확한 4단계 클리어 목표를 둔다. 이는 사용자의 '다 클리어' 요청을 반영한 변경이며 구현 전 검토 대상이다.

난이도 클리어 보상은 각각 200/400/800/1600뿌다. 실패 보상은 현재 난이도의 완료 웨이브 수를 n이라고 할 때 `(5 + 2n) × 1/2/4/8`뿌다. 이전 난이도 클리어 때 지급한 보상을 다시 지급하지 않는다. 0웨이브 실패도 기본 보상을 받는다. 결과 화면에 이번 보상과 누적 잔액을 나란히 표시한다.

## 병사 접촉 전투
보병 막사와 돌격병 기지의 병사는 시설에서 생성되어 좀비에게 접근하고 접촉 거리 안에서 일정 간격으로 피해를 준다. 서로 체력이 줄어 0이면 사라지며, 단 한 번 닿았다는 이유만으로 병사가 소모되지는 않는다. 접촉 타격 효과와 피해 숫자를 표시한다. 중화기·드론·전차는 기존 원거리 역할을 유지한다. 시설별 4명 상한과 4단계 강화는 유지하고 강화한 기지는 더 높은 능력치의 병사를 생성한다. 보급소는 기존 주변 공격력 지원 역할을 유지한다.

## 배속
방장이 1×/2×/3× 중 선택한다. 같은 방의 모든 플레이어에게 동일한 서버 시뮬레이션 속도를 적용한다. 이동·공격·소환·웨이브 준비·지속 효과가 같은 비율로 빨라지고, 고정된 작은 시간 간격을 여러 번 계산해 공격과 지급이 누락되지 않게 한다. 연결 보존 2분은 실제 시간 기준이다. 방장이 연결을 잃으면 연결된 플레이어에게 조작 권한을 넘긴다.

## 좀비 종류와 속성
기본 체력·속도에 아래 배율을 적용하고 별도의 난이도 배율과 조합한다. 크기는 화면상의 외형과 근접 접촉 반경에 함께 반영한다. 작은 적은 여러 발 빠르게 쏘는 시설, 큰 적은 높은 단일 피해, 무리는 범위 공격에 유리하도록 역할을 구분한다.

| 종류 | 크기 배율 | 체력 배율 | 속도 배율 | 특징 |
| --- | --- | --- | --- | --- |
| 일반 좀비 | 1 | 1 | 1 | 기본 적 |
| 질주 좀비 | 0.65 | 0.65 | 1.7 | 작고 빠름 |
| 거대 좀비 | 1.8 | 4 | 0.6 | 느리지만 높은 체력 |
| 장갑 좀비 | 1.15 | 2 | 0.8 | 관통을 제외한 피해 35% 감소 |
| 재생 좀비 | 1.1 | 1.8 | 1 | 초당 최대 체력의 1% 회복, 화염 지속 피해 중 재생 중지 |
| 분열 좀비 | 1.2 | 1.6 | 0.9 | 사망 시 작은 좀비 3마리 생성 |

분열 자식은 부모가 죽은 경로 진행도에서 태어나며 부모 최대 체력의 25%, 기본 속도의 1.3배, 크기 0.55배다. 자식은 다시 분열하지 않는다. 부모와 자식 전체 처치 보상의 합은 원래 한 마리의 책정 금액과 동일하게 하며 부모 사망 시 찌를 먼저 중복 지급하지 않는다. 자식이 남아 있으면 웨이브를 완료하지 않는다. 동시에 살아 있는 적은 200마리를 넘지 않도록 분열 출생 여유를 예약하고, 부족할 때는 경로 진행도를 보존한 대기 출생으로 처리한다. 대기 출생도 웨이브 종료 판정에 포함한다.

속성은 종류와 독립적인 화염·냉기·전기의 3가지다. 화염 속성은 화염 피해 50% 감소, 냉기는 둔화 강도 절반, 전기는 전기 피해 50% 감소로 적용한다. 완전 면역은 두지 않으며 각 저항을 설명하는 작은 아이콘과 색 테두리를 표시해 색만으로 구분하지 않게 한다. 장갑의 일반 피해 감소와 원소 저항은 각각 한 번만 적용한다.

보통은 일반·질주에서 시작해 이후 맵에서 거대·장갑·분열·재생을 순서대로 소개한다. 어려움부터 속성이 붙은 적을 혼합한다. 지옥과 불가능에서는 속성 적의 비율과 특수 적의 조합을 높인다. 지역별 보스는 기존 고유 능력과 큰 외형·상단 체력바를 유지한다. 새 적이 처음 등장하는 준비 시간에 종류·속성과 대처 정보를 표시한다.

## 타워 상점과 인벤토리
기존 18종은 유지하며 웨이브 해금도 그대로 적용한다. 난이도 클리어마다 별도 타워의 구매 자격이 열린다.

| 필요 클리어 | 신규 타워 | 구매 가격 | 전투 내 건설비 | 역할 |
| --- | --- | --- | --- | --- |
| 보통 | 방패병 기지 | 200뿌 | 300찌 | 높은 체력의 근접 병사 |
| 어려움 | 중력탑 | 400뿌 | 600찌 | 범위 둔화와 지속 피해 |
| 지옥 | 궤도포 | 800뿌 | 1000찌 | 긴 재장전의 강한 범위 공격 |
| 불가능 | 워메크 기지 | 1600뿌 | 1600찌 | 강한 장갑 병력 소환 |

인벤토리는 구매한 타워를 표시하고 다음 전투의 건설 목록에 넣거나 뺄 수 있게 한다. 기본 시설 18종은 처음부터 소유하며 추가 슬롯 수 제한은 두지 않는다. 실제 설치 제한은 기존 방당 100개다. 장착 목록은 새 방 입장 시 반영하고 진행 중에는 바꾸지 않는다. 모든 시설을 빼서 시작 불가능해지는 상황을 막기 위해 기관총·보병 막사·은행은 기본 구성으로 유지한다. 구매 자격, 잔액과 소유 여부는 서버에서 검사하며 중복 구매는 중복 결제하지 않는다.

## 플레이어 무기와 핵폭탄
뿌로 구매하는 영구 타워와 달리 플레이어 무기는 이번 전투의 찌로 구매한다. 개인별로 소유하며 여러 무기를 구매한 뒤 하나를 선택할 수 있다. 새 게임에서는 무기 보유가 초기화된다. 구매 직후 선택하되 자동 발사는 별도 `발사 시작` 버튼을 눌러 활성화한다. 다시 누르면 `발사 중지`가 되어 멈춘다. 모든 총은 게임 시간 기준 1초마다 발사하며 배속을 따라간다. 살아 있는 적이 없으면 탄환·효과음을 만들지 않는다.

| 무기 | 가격 | 1초당 공격 | 역할 |
| --- | --- | --- | --- |
| 기본 총 | 1000찌 | 단일 80 피해 | 최초 구매 무기 |
| 산탄총 | 2500찌 | 최대 5개 대상에 각 30 피해 | 밀집된 적 제압 |
| 레일 라이플 | 7000찌 | 단일 450 관통 피해 | 장갑·보스 대응 |
| 플라스마 캐논 | 15000찌 | 250 피해, 반경 100 | 강한 범위 공격 |
| 핵폭탄 | 사용당 5000찌 | 보스 외 모든 좀비 즉사 | 일회성 전장 정리 |

총알은 플레이어 색으로 팀 기지에서 가장 멀리 진행한 적에게 향한다. 총 피해·재장전·구매 금액·무기 소유권은 서버가 판정한다. UI에 선택 무기·보유 여부·구매 금액·발사 상태를 구분한다. 기본 총을 구매하지 않았을 때 발사 버튼은 구매 필요 상태로 표시한다.

핵폭탄은 `핵폭탄 사용 · 5000찌` 전용 버튼으로 즉시 구매·사용하고 방 전체에 30게임초의 재사용 대기시간을 둔다. 현재 살아 있는 비보스와 분열 대기 자식을 모두 제거한다. 이 제거는 장갑·원소 저항을 무시하고 추가 분열을 발생시키지 않으며 보스 체력을 바꾸지 않는다. 비보스 처치 보상은 기존 기여 규칙대로 한 번만 지급하고 뿌는 지급하지 않는다. 아직 웨이브에서 출현하지 않은 일반 적은 이후 정상 출현한다. 비보스가 없거나 보스만 있을 때는 사용을 거부하고 돈을 차감하지 않는다. 동시에 여러 플레이어가 누르면 먼저 성공한 한 번만 결제·사용한다.

## 프로필 저장과 접근
브라우저에 프로필 복귀 키를 저장하고 서버는 프로필별 뿌·클리어 기록·구매·장착 목록을 JSON 파일에 원자적으로 저장한다. 비밀 키는 공유 방 URL이나 전체 방 상태에 노출하지 않는다. 동시 구매와 보상 정산은 순서대로 처리하고 저장 실패 시 성공으로 표시하지 않는다. 저장 위치는 환경 변수로 지정 가능하게 하고 기본 데이터 폴더는 Git에서 제외한다. Node 실행 사용자에게 해당 폴더 쓰기 권한을 제공한다.

서버 파일은 재시작 후 유지되지만 방의 전투 자체는 복원하지 않는다. 사용자가 브라우저 데이터를 지우거나 다른 기기에서 접속하면 자동으로 같은 프로필을 찾을 수 없다. 계정 연동·기기 간 이전은 이번 범위에 포함하지 않는다. 공개 호스팅은 데이터 디렉터리를 영속 볼륨에 보관해야 한다.

## 배경음악과 효과음
어두운 생존 분위기의 낮은 드론음·박동 리듬 배경음악을 제공하고 보스 출현 시 긴장감 있는 패턴으로 전환한다. 별도 외부 음원 다운로드 없이 Web Audio로 직접 합성한 음을 사용한다. 사용자가 작전 시작 등 버튼을 누른 후 오디오를 활성화하며, 브라우저 정책으로 재생이 중지되면 소리 켜기 버튼을 제공한다. 게임 입장은 오디오 재생 성공 여부와 무관하게 동작한다.

총격·근접 타격·폭발·화염·전기·피격, 건설·강화·구매, 웨이브 시작·완료, 보스 출현, 승리·패배 알림음을 구분한다. 서버 이벤트 ID와 상태 전환을 기준으로 한 번만 재생하고 재접속으로 지난 효과음을 한꺼번에 재생하지 않는다. 동시 효과음 수는 최대 12개로 제한하며, 배속에서도 안내음은 반복·겹침 없이 들려준다. 음악 기본 음량은 25%, 효과음은 50%로 두고 개별 슬라이더와 전체 음소거를 제공한다. 설정은 브라우저에 저장한다. 배경 탭에서는 재생을 일시 중지하고 게임 종료 시 배경음악 패턴을 정리한다.

필수 오디오 검증은 사용자 입력 이후 오디오 활성화, 음악·효과음별 음량과 음소거 저장, 동일 이벤트 중복 재생 방지, 보스 패턴 전환, 최대 동시 재생 수, 오디오 사용 불가 시 입장·전투 정상 진행이다. 자동 검증으로 오디오 이벤트와 설정을 검사하고 실제 청취 확인 여부는 구분해서 보고한다.

## 화면과 검증
로비에 보유 뿌, 상점·인벤토리, 구매 조건과 장착 상태를 표시한다. 전투 HUD는 찌·난이도·지역·배속을 구분한다. 결과 화면에서 성공/실패와 보상, 새 구매 자격, 다시 시작을 제공한다. 입장 오류는 입력란 근처에 표시하고 혼자 시작하는 경로를 명확하게 표시한다.

필수 검증: 전장 클릭당 본인에게만 1찌 지급·금액 변조 무시·종료 후 지급 거부·배속과 무관한 단가·드래그와 UI 클릭 제외, 총 구매 비용·소유권·1초 발사 간격·시작/중지·적 없는 발사 억제, 핵폭탄 보스 제외·분열 억제·동시 사용 단일 결제·대기시간·빈 전장 차감 거부, 좀비 크기·속도·저항 배율, 화염 중 재생 중지, 분열 1세대 제한·경로 유지·보상 중복 방지·출생 대기 포함 웨이브 종료·200마리 상한, 근접 병사의 이동·접촉 피해·죽음·강화, 3배속의 누락 없는 진행, 실제 시간 재접속 만료, 5개 맵마다 난이도 변화, 최종 클리어, 실패 보상·중복 정산 방지, 구매 조건·중복 결제 방지, 저장 실패와 재시작 복원, 새 게임에 장착 목록 반영, 기존 1~4인 방 코드와 재접속 회귀. 브라우저에서 1인 입장→시작과 협동 배속 공유, 전장 클릭 수입과 별도 무기 조작, 좀비 외형·속성 안내, 상점·인벤토리·결과 화면을 확인한다. Sites 게시 도구는 여전히 없으며 이 작업의 완료를 Sites 배포 완료로 표현하지 않는다.
