# 밝은 폐허 도시 업데이트

사용자가 대화에서 정한 기존 게임 수정: 난이도 구분 대신 30스테이지, 갈수록 증가하는 좀비 레벨·수량, 생존자 레벨업·총 강화, 10/20/30의 서로 다른 보스, 지상·공중·해상 침입, 밝은 폐허 도시. 추가 지시: 군인은 모집 타워에서 나오는 대신 오른쪽 기지에서 출발하여 도로를 따라 이동한다. 온라인 공개 배포는 이후 요청까지 보류한다.

구현: 기존 서버·오프라인 공통 시뮬레이션을 유지한다. 도시의 5개 구역을 6스테이지마다 이동하며 시설비를 환급한다. 해상 경로와 공중 직행 경로를 추가한다. 군인은 모집 시설과 가장 가까운 지상 경로를 선택하고 기지에서 그 길을 따라 적을 향해 이동한다. 공격 범위 밖의 적을 쫓아 길을 이탈하지 않는다. 일부 좀비는 시설을 사격하고 최종 보스는 주변 시설과 군인에 오염 피해를 준다.

생존자 레벨 최대30, 공격력 레벨당+4%. 무기 강화 최대10, 강화당 기본 피해+35%, 강화비는 기본 가격의 50%×현재 레벨. 스테이지 수입 100+15×스테이지찌. 보스 보상 200/400/1600뿌, 실패 보상 5+3×완료 스테이지뿌. 모든 기본 타워는 늦어도25 클리어에 해금. 보너스 타워 자격은10/20/30 클리어. 기존 영구 프로필·구매 기록은 보존한다.

배포: 루트 play-solo.html은 build:solo로 생성되는 단일 파일이다. 외부 자원이나 Node가 필요 없고 프로필은 메모리에만 유지한다. GitHub ZIP 안에 포함한다. 서버의 저장·협동 기능은 기존 실행법으로 유지한다. 사용자 요청에 따라 공개 호스팅은 하지 않는다.

검증: 신규 캠페인/경로/무기/시설 공격/군인 도로 이동 검사 RED 확인 후 GREEN. 전체 서버49개 통과. 실제 파일 주소 탐색은 이 환경 Chromium의 관리자 정책으로 차단되므로 HTML 내용을 직접 브라우저에 로드하는 기존 오프라인 검사를 사용한다. 이 검사는 외부 HTTP/WebSocket 요청이 없음을 검증한다. Windows 파일 더블클릭과 장기 밸런스·실기기 오디오는 확인하지 못했다.

최종 결과: npm test 49/49, npm run test:browser 15/15, npm run test:solo 1/1 통과. 데스크톱 및 모바일 스크린샷을 확인했다. 브라우저에서 총 구매 후 강화 버튼의 실제 차감과 레벨 변경도 확인했다. 단일 HTML 크기 약122KiB. 별도 새 컨텍스트 리뷰 없이 작성자 검토와 회귀 검사로 검증했다.
