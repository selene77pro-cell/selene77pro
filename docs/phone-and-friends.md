# 카톡으로 게임을 보내려면

친구에게 ZIP 파일 대신 **인터넷 게임 주소**를 보내면 휴대폰에서 바로 열 수 있습니다. 이를 위해 게임 서버를 한 번 인터넷에 올려야 합니다.

[게임을 인터넷에 올리기 (Render)](https://render.com/deploy?repo=https://github.com/selene77pro-cell/selene77pro)

1. 위 버튼을 열고 Render에 가입하거나 로그인합니다. GitHub 로그인을 사용할 수 있습니다.
2. 이 저장소 `selene77pro-cell/selene77pro` 연결을 허용합니다.
3. 배포 화면에서 **Free(무료)** 요금인지 확인한 뒤 배포합니다. 유료 업그레이드를 선택할 필요는 없습니다. 서비스 제공자의 가입 조건은 달라질 수 있습니다.
4. 완료되면 제공되는 `https://…onrender.com` 주소를 엽니다. 이 주소가 게임 주소입니다. 이 문서 자체는 배포 완료를 의미하지 않습니다.
5. 닉네임으로 들어가 전투 상단의 **카톡으로 초대**를 누릅니다. 카카오톡이 나오면 선택하거나, 복사된 링크를 카톡에 붙여넣습니다. 친구도 닉네임을 적으면 같은 방에 들어옵니다. 최대 4명입니다.

## 알아둘 점

무료 서버는 한동안 사용하지 않으면 쉬었다가 다시 켜지므로 첫 접속이 늦을 수 있습니다. 서버가 재시작되면 진행 중인 방과 **뿌·타워 구매 기록도 초기화될 수 있습니다**. 무료 서버의 로컬 파일은 영구 저장소가 아니기 때문입니다. 장기 기록 보존은 별도의 영구 저장 설정이 필요합니다. 이 배포 설정은 유료 디스크를 만들지 않습니다.

휴대폰 세로·가로 화면 모두 사용할 수 있습니다. 카톡 안에서 소리나 화면 조작이 불편하면 메뉴에서 Chrome/삼성 인터넷으로 열어 주세요. 실제 안드로이드와 카톡 앱은 자동 브라우저 테스트와 별도로 확인해야 합니다.

`play-solo.html`은 인터넷 서버가 필요 없는 혼자 연습용입니다. 파일을 친구에게 보내도 각자 혼자 플레이하며 같은 방에서 만날 수는 없습니다.
